XR Projects · Concept sprint

Ten ways to unbox a bottle

Low-fidelity wireframes for a 3D whiskey unboxing site, built around a placeholder distillery called Kestrel & Oak. Each one is a different way to interact with the box. Numbered pins match the notes under each frame.

01

Scrub to Unbox

ScrollEffort · MediumLaunch story

The whole page is one pinned 3D scene, and the scroll position drives a single unboxing timeline. It's slow and cinematic. Nothing moves unless the visitor scrolls.

  1. Sealed box, slow turntable
  2. Wax seal cracks
  3. Lid lifts, tissue parts
  4. Bottle rises into key light + CTA

Pins

  1. Chapter rail, also click-to-jump nav
  2. Motion scrubbed by scroll, not autoplay
  3. Caption swaps per chapter

Build notes

One Blender animation clip exported as GLB, scrubbed with GSAP ScrollTrigger driving the AnimationMixer time. This is the cheapest way to get a lot of motion.

02

Sticky Product Stage

Scroll + orbitEffort · Low–MedE-commerce

This one is built for e-commerce first. The 3D stage stays pinned on the left while the right column scrolls through chapters, and each chapter re-poses the box and bottle. It's the same skeleton as the necklace page, so most of the scaffold carries over.

  1. Closed box + price above the fold
  2. "The Cask": box opens, bottle turns to cask stamp
  3. "The Spirit": label close-up
  4. Buy block

Pins

  1. Sticky canvas with free orbit
  2. Chapter tabs mirror scroll position
  3. Buy block always one scroll away

Build notes

Camera + model poses tweened per chapter via IntersectionObserver. Collapse the canvas to the top half on mobile.

03

Pull the Ribbon

DragEffort · MediumTactile

The visitor opens the box with their own hands. Nothing is revealed until they pull the ribbon, lift the lid, and fold back the tissue. Each step is a drag with a little resistance and a satisfying sound.

  1. Ribbon pull (progress ring)
  2. Drag lid upward
  3. Swipe tissue aside
  4. Bottle settles, product sheet slides up

Pins

  1. Ribbon handle + progress ring
  2. Sound toggle (paper, cork pop)
  3. Step tracker; "skip" fallback top-right

Build notes

Raycast drag on three.js meshes, a damped spring for the resistance, and Web Audio for the sounds. Touch works with no extra code.

04

Exploded Craft

Slider + hoverEffort · MediumCraft detail

This uses the same exploded-view language as the Pegasus watch. Every part of the package floats apart along one axis, and hotspots tell the craft story behind each part. It's the most product-honest of the ten.

  1. Assembled package
  2. Explode via slider / scroll
  3. Hover hotspot → craft card
  4. Snap back together

Pins

  1. Hotspot expands into a craft card
  2. Explode slider (or bind to scroll)

Build notes

Per-part Y offsets lerped from one 0–1 value. CSS2DRenderer for the labels so the text stays crisp.

05

Grain to Glass

Horizontal scrollEffort · HighBrand story

The track is pinned horizontally, and a single object morphs through every stage of making the whisky: barley, still, cask, bottle, and finally the closed box. The unboxing comes at the very end, once the visitor has earned it.

  1. Barley field
  2. Copper still
  3. Cask; age counter ticks to 18
  4. Bottle → box closes → CTA

Pins

  1. Pinned track, active stage outlined
  2. Progress thumb (draggable)

Build notes

ScrollTrigger pin with an x-translate. Dissolve shader between models instead of true morphs to keep the effort sane.

06

Collector's Cabinet

ClickEffort · MediumRange page

A range page instead of a single bottle. A wooden cabinet holds every boxed expression. Click one and it slides off the shelf into a drawer, where it unboxes. Compare mode puts two open bottles side by side.

  1. Cabinet overview
  2. Hover lifts a box off the shelf
  3. Click: slides into drawer & opens
  4. Compare two side by side

Pins

  1. Shelf grid with hover lift
  2. Detail drawer with its own 3D view
  3. Unbox / Compare actions

Build notes

One box model with swapped label textures per expression, and one shared unbox clip, so new products don't need new 3D work.

07

The First Pour

Scroll + hoverEffort · HighSensory

The unboxing doesn't end at the bottle. It ends in the glass. Once the bottle is out, it tips and pours, the glass fills to amber, and a flavor wheel lights up the tasting notes. This is the most sensory of the ten.

  1. Bottle lifts from box
  2. Tilt + pour
  3. Glass fills to the right colour
  4. Flavor wheel lights notes

Pins

  1. Pour stream (scroll-scrubbed)
  2. Flavor wheel: hover segment for a note
  3. Nose / Palate / Finish tabs re-light the wheel

Build notes

Fake the liquid with a stream mesh and a fill-level uniform on the glass. The wheel is plain SVG layered over the canvas.

08

Build the Gift

ConfigureEffort · MediumGifting / checkout

The unboxing runs in reverse. The visitor puts together their own gift: they pick an expression, a case finish, an engraving, and a note. Then they watch the box close and the wax seal stamp down. This is the strongest of the ten for conversion.

  1. Pick bottle; it drops into case
  2. Swap case finish live
  3. Type engraving onto lid
  4. Lid closes, seal stamps → checkout

Pins

  1. Step list (editable at any time)
  2. Live box with engraving texture
  3. Sticky price + checkout bar

Build notes

Material variants on one GLB. Engraving is a canvas texture redrawn on each keystroke and blended into the roughness map so it looks pressed into the wood.

09

Cellar by Candlelight

CursorEffort · MediumAtmosphere

A dark, atmospheric discovery. The page is a dim cellar, and the cursor is a candle. The visitor searches for three hidden objects (a key, a letter, a cask stamp), and finding all three unlocks the crate. This is the most memorable of the ten, and the one people are most likely to share.

  1. Darkness, faint crate silhouette
  2. Light reveals clues
  3. Third find unlocks crate
  4. Lights rise, bottle fully lit

Pins

  1. Light cone follows the pointer
  2. Hidden object (glints when lit)
  3. Find counter; "Lights on" skip for accessibility

Build notes

A three.js SpotLight that follows the pointer, plus a dim ambient light. On mobile, tilt the phone (device orientation) or drag a finger to move the light.

10

Hands-on Unbox

Camera + AREffort · HighXR showcase

This is the XR flagship. Webcam hand tracking lets the visitor pinch the ribbon and lift the lid in mid-air. On a phone, "View in your room" puts the box on their table. It reuses the hand-tracking work from the fingertip desktop.

  1. Allow camera
  2. Pinch to grab ribbon
  3. Raise hand → lid lifts
  4. Open palm presents bottle → AR handoff

Pins

  1. Webcam picture-in-picture with landmarks
  2. Hand-driven lid, mapped from pinch distance
  3. AR button (mobile) / QR (desktop)

Build notes

MediaPipe Hands for tracking, and <model-viewer> for AR (GLB + USDZ). Without a camera it falls back to the #03 drag interaction.

If I had to build one

Combine 02 + 03 + 07. Start with the sticky product stage, since it shares a scaffold with the necklace page. Swap the scroll-driven opening for the ribbon pull, and end on the pour with the flavor wheel. You get a tactile moment, a sensory payoff, and a buy button that's always in reach. Hold 10 back as an optional "try it with your hands" mode for the XR portfolio angle.
